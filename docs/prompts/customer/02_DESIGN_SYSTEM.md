# CUSTOMER WEBSITE — 02_DESIGN_SYSTEM

## Objective

Design and implement the complete reusable Design System for the HOPSY PLAZA Customer Website.

This task is responsible **only** for the visual foundation and reusable UI components.

Do **not** build actual business pages such as the homepage, shop, product pages, cart, checkout, or customer dashboard.

# Step 3 — Design Philosophy

The design system should communicate:

* Professional
* Modern
* Premium
* Trustworthy
* Clean
* High-end electronics retailer

The visual quality should be comparable to established electronics retailers while remaining uniquely branded for **HOPSY PLAZA**.

---

# Step 4 — Brand Identity

Primary brand colors:

* White
* Orange

Supporting colors should complement the primary palette.

Avoid introducing unnecessary accent colors that dilute the brand identity.

Color usage should create hierarchy rather than decoration.

---

# Step 5 — Forbidden Design Patterns

Never introduce:

* AI-looking layouts
* Generic Tailwind UI
* Oversized hero sections
* Cartoon illustrations
* Floating stickers
* Floating live indicators
* Glassmorphism
* Neon gradients
* Random glowing cards
* Excessive blur
* Overly rounded interfaces
* Poor spacing
* Inconsistent iconography
* Decorative elements without purpose

Every component should feel intentionally designed.

---

Create a complete typography scale including:

* Display

* Body
* Body Small

* Label
* Button Text

* Letter spacing

# Step 8 — Spacing System

Define:

* Margins
* Padding
* Gaps

# Step 9 — Border Radius & Elevation

* Border radius
* Shadows
* Elevation

* Stroke widths

* Placement
* Button icons
* Navigation icons
* Status icons

# Step 15 — Motion System

Implement premium animations using **Framer Motion**.

Animation principles:

* Smooth
* Subtle
* Purposeful
* Fast
* Consistent

Include motion presets for:

* Page transitions
* Dialogs
* Drawers
* Hover effects
* Loading transitions
* List appearance

Animations should enhance usability rather than distract.

---

# Step 16 — Responsive Design Standards

Design for:

* Mobile-first
* Tablet
* Laptop
* Desktop
* Large Desktop

Components should adapt gracefully without requiring redesign.

* Keyboard navigation
* Focus indicators
* Screen readers
* Semantic HTML
* Appropriate ARIA attributes
* Color contrast requirements

Accessibility should be built into every component.
