# Part 1 — Customer Experience Vision, Design Principles & Global Layout

---

# 1. Purpose

This document defines the complete UI/UX specification for the HOPSY PLAZA Customer Website.

Its purpose is to ensure AntiGravity produces a premium, production-quality e-commerce experience that feels professionally designed by an experienced product design team rather than AI-generated.

This document governs:

* Visual language
* User experience
* Layout hierarchy
* Responsive behavior
* Components
* Navigation
* Animations
* Accessibility
* Interaction patterns

It takes precedence over generic templates or autogenerated layouts.

---

# 2. Design Vision

The customer website should combine the strongest qualities of:

* Apple Store
* Samsung
* Best Buy
* Sony
* Bose
* Framework

The experience should feel:

* Premium
* Modern
* Fast
* Trustworthy
* Elegant
* Professional
* Minimal
* Product-focused

The interface should encourage purchasing without overwhelming the user.

---

# 3. Overall Design Philosophy

The website should communicate quality through restraint.

Prioritize:

* Clean composition
* Strong typography
* Consistent spacing
* Excellent photography
* Logical information hierarchy
* High usability
* Fast interaction

Avoid decorative elements that do not improve usability.

---

# 4. Anti-AI Design Rules

The website must **not** resemble an AI-generated template.

The following are prohibited:

* Generic Tailwind layouts
* Oversized hero sections
* Random floating cards
* Floating "Live" badges or animated dots
* Glassmorphism
* Neon gradients
* Cartoon illustrations
* Emoji-based UI
* Sticker-like decorations
* Excessive glow effects
* Auto-generated dashboard aesthetics
* Excessive border radius
* Poor spacing rhythm
* Repetitive card layouts
* Inconsistent icon styles

Every page should appear intentionally designed.

---

Brand

HOPSY PLAZA

Primary Colors

* White
* Orange

Supporting Colors

* Neutral Gray Scale
* Black
* Soft Silver

Accent colors should be used sparingly to emphasize important actions.

The interface should never feel saturated with orange.

---

# 6. Typography

Typography should establish a strong visual hierarchy.

Characteristics:

* Modern
* Clean
* Highly legible
* Professional

Requirements:

* Consistent heading scale
* Comfortable paragraph width
* Balanced line height
* Proper font weights
* Predictable spacing

Typography should carry much of the visual identity.

---

# 7. Iconography

Icons should be:

* Consistent
* Minimal
* Modern
* Thin or medium stroke
* Professionally aligned

Icons should communicate functionality rather than decoration.

---

# 8. Spacing System

Spacing should follow a consistent design rhythm.

Requirements:

* Consistent vertical spacing
* Consistent horizontal spacing
* Predictable section padding
* Balanced whitespace
* Proper alignment

Whitespace should improve readability rather than appear empty.

---

# 9. Grid System

Layouts should use a responsive grid.

Requirements:

* Consistent content width
* Responsive columns
* Proper gutters
* Predictable alignment

Products should align perfectly regardless of screen size.

* Mobile Phones
* Large Phones
* Tablets
* Small Laptops
* Large Laptops
* Desktop Monitors
* Ultra-wide Displays

No layout should break across supported viewport sizes.

* Every page follows the documented design system.
* Navigation is intuitive across all supported devices.
* Authentication flows are secure and user-friendly.
* Shopping, checkout, and post-purchase experiences are seamless.
* Product discovery is efficient through search, filtering, and categorization.
